# 90秒演示脚本

这是硬件验收完成后的预期现场流程。当前硬件仍暂停，不能将以下步骤介绍成已经实测完成。

## 0—15秒：让观众知道为什么走近

「它叫布服，口号是『你的穿搭，它有意见』。你穿得越有想法，它越有话说。」

说明自愿参与、只评衣服；现场拍摄与云端处理需让参与者知情。

## 15—45秒：一轮完整体验

参与者站入已验证的彩色镜头范围，说「锐评一下」。先取得单帧，处理时可播放单独验收过的短思考示教，只有真实结果生成后才播报。成功点评的收尾是「下一个」，可配合经过验证的挥手。未启用动作时保留纯语音流程，不宣称机器人的表演动作是模型的内部推理。

若图像看不清，就按实际重拍提示处理，不让操作员用预写台词冒充结果。

## 45—70秒：制造第二轮的理由

「不服，换一身再来。」

请参与者改变一个可见元素，例如拿掉帽子、换件外套，重新发出口令。每轮独立看图；不宣称它记住了这个人或比较了历史穿搭。

## 70—90秒：讲出项目判断

「穿搭是每个人自带的互动道具。我们想验证，有性格的机器人能否让人愿意主动走近、再试一次，并把朋友叫来。」

用实际记录讲清本轮调用的视觉模型和声音服务；不把发送音频帧说成已确认出声。

## 硬件尚未通过时

可以展示已有测试图与其真实API生成的音频，但必须先说：「这是测试图生成的样例，现场相机与喇叭还在验收。」

不要把预生成声音配上机器人画面，暗示机器人正在实时看人、聊天或行动。
