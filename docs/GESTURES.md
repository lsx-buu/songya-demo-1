# 动作与锐评v3

更新日期：2026-11-01。本文描述代码能力；不表示现场动作已经验收。此前意外移动仍未归因，当前硬件测试没有恢复。

## 一轮互动的节奏

1. 说「锐评一下」，收音会话关闭后拍一张照片。
2. 拍照完成后，开始一次已核验的短思考示教；视觉点评与声音合成同时处于这个阶段。动作不会反复循环，也不代表模型内部思考。
3. 播报锐评前检查思考动作是否已报告进入相应模式并返回准备好的模式；未确认时停止后续应用任务并提示核查，绝不自动发复位指令。
4. 点评音频按帧发送结束后留250ms间隔，再尝试一次挥手并播放「下一个」。这只是发送时序，真实喇叭延迟及听感仍需验收。
5. 拍不清时只提醒重拍，不挥手赶人，不说「下一个」。云端失败不会用样例台词冒充结果。

## 原厂接口与限制

[厂家 HighController 文档](https://web.noetixrobotics.com/docs/#五应用开发-highcontroller)列出出厂挥手 `SWING` 与示教播放 `PLAYTEACH`；没有名为 THINK 的预设动作。思考只预留已验证示教的播放入口，当前没有提供、录制或验收一套思考关节轨迹。不要把擦眼泪等其他预设动作当成思考。

本应用只在两个固定阶段允许两个固定命令，参数 `x/y/z` 均为0，单次发送。模型返回的文字、标题与图片文字均不参与动作选择，也不能提供命令或示教编号。没有行走、自动上电、起身、模式复位、录制示教或唤醒原厂系统的调用。

发送前要求：硬件和动作开关都明确启用、对应动作已核验、现场许可仍有效；收到完整21个唯一电机的有效新鲜状态，整体 `workmode=2`，无电机错误，有限且较低的关节速度。关节速度检查不能证明机器人底座绝对静止，也不能限制原厂进程。

指令有8秒冷却，不插队、不重试。状态过期、异常、被撤销许可或从发送开始12秒内未看到预期模式往返，均锁住后续动作并取消应用剩余任务。程序不会把取消自身任务说成机器急停。

只有 `sent` 或 `returned_ready` 软件记录，`observed=false` 始终保留；不能当成动作幅度、稳定性或现场安全的证明。动作如果不会自动回到已验证的就绪模式，当前适配会拒绝接续，须先由厂家明确其结束机制。

## 默认配置

`robot.json` 是私有设备文件，不提交到仓库。以下是关闭状态的示例，不包含动作编号：

```json
{
  "hardware_enabled": false,
  "gestures_enabled": false,
  "wave_verified": false,
  "thinking_verified": false,
  "thinking_teach_index": null,
  "gesture_sdk_root": ""
}
```

`gesture_sdk_root` 需由现场选定配套 SDK 的绝对路径。扩展需要 `build/highcontrol_py*.so`、配套动态库和 `config/dds.xml`，DDS文件内容必须与媒体已经选定的配置一致；程序不会代替操作员修改DDS。可使用同时包含兼容媒体和动作扩展的隔离SDK目录，动态库需在进程启动前可解析。厂家二进制不在本仓库中。

新增/修改动作配置需要显式重启才能生效；运行中改配置只允许撤销已有许可。当前不提供一条直接开动作的命令，必须先满足现场条件并逐项验收。程序也不会自动录制示教。

## 让锐评更尖锐

`outfit/prompts.py` 中 `roast-v3` 默认毒舌档。要求至少两个真实可见的衣服特征，一个搭配矛盾，短句和最后一句补刀；禁止客气夸奖、圆场与改造建议。只嘲讽服装搭配，不攻击身材、脸、肤色、性别、经济状况或真实身份。

语气示例，仅供理解力度，不是实拍识别：

> 黑西装在谈收购，白球鞋在等下课。公司还没上市，员工先放学了。

`suggestion` 即使被模型填写也会清空。重拍结果的 `roast` 也会清空。模型本身仍可能偶尔不够好笑；没有用本地段子替换真实接口结果。

## 调试依据

- `robot_service.py --check` 仅检查配置和文件，不加载设备SDK。
- 状态文件 `data/robot-status.json` 可看到 `capturing/reviewing/synthesizing/speaking/dismissing/turn_finished`。
- 私有 `data/api-audit.jsonl` 按 `run_id` 关联视觉、两段合成音频、播放和动作事件；含 `prompt_version=roast-v3`、服务端响应ID及 `phase`。
- 动作关闭时同样记录 `skipped` 及原因，避免把原厂的自行发声或动作算成本应用成功。
- 自动测试只用替身验证接口字段、固定指令、状态门槛、取消与编排；不访问实体机器人，不代表物理验收。
