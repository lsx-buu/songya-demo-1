# 项目报名文案

**项目名称：布服 BUFU**

**项目标语：你的穿搭，它有意见。**

## 项目描述（约200字）

「布服」是一款以穿搭锐评为入口的机器人社交互动项目。用户说出“锐评一下”，系统按语音触发、单帧看图、生成短评、语音播报的流程，让机器人用有性格的吐槽回应眼前穿搭。它聚焦服装与配饰的具体细节，通过换外套、摘帽子等轻操作形成复玩，面向多人围观和轮流挑战。系统采用机器人本机调度与云端模型协作，保留调用来源记录，不保存原图。目前已完成本机部署及真实云端链路验证，现场相机与扬声器仍待验收。

## 功能与创新点

- **看图现编梗**：围绕实际可见的单品与搭配冲突生成吐槽，让笑点对应眼前场景。
- **有性格的机器人角色**：统一冷面、嘴欠、有分寸的表达，只评衣服，不攻击外貌与身材。
- **轻量复玩机制**：换一个配饰就能再次挑战，将穿搭变成参与者自带的互动道具。
- **可追溯的生成链路**：关联视觉请求、模型来源与合成音频，支持核对每轮结果。

## 拟应用场景

- 科技展会、黑客松：展示机器人视觉理解与语音互动。
- 校园市集、社群活动：自愿参与的穿搭挑战与现场破冰。
- 品牌快闪、服饰体验区：结合主题人设开展互动，具体商业效果有待验证。
