# 布服 · BUFU

**你的穿搭，它有意见。**

一个用穿搭锐评破冰的机器人项目。我们设计的体验很短：走到机器人面前，说「锐评一下」，它拍一张穿搭照，抓住衣服之间最明显的冲突，用一句冷面吐槽把它说出来。

**不服，换一身再来。**

## 为什么做布服

机器人可以拥有一个让人记住的性格。布服从一件人人能看见、随手能改变的东西开始：今天穿的衣服。

穿搭提供视觉线索，声音把结果带给身边的人。一件外套、一顶帽子就能带来下一轮互动。我们想验证：一个看得懂眼前细节、说话有分寸又有梗的机器人角色，能否让人愿意主动走近、复玩，并把朋友叫来。

首版聚焦一个体验，不加入走路、挥手、打分、排行榜或长期记忆。先把一次互动做成立得住的笑点。

## 预期互动

```text
「锐评一下」
    ↓
机器人麦克风 → 豆包口令识别
    ↓
本机相机单帧 → 方舟视觉模型 → 短锐评
    ↓
豆包指定文本合成 → 机器人内置扬声器
```

这是一条典型台词的节奏示例，不是某张现场照片的识别结果：

> 卫衣在扩建，裤子在征地。你这身还没开始做造型，先把城市规划做完了。

只损衣服和搭配，不评价身材、五官、肤色、性别或真实身份。看不清就要求重拍；调用失败不会拿样例冒充模型输出。

## 运行与配置

目标环境是匹配媒体 SDK 的 Jetson Linux / Python 3.10+。展示名为「布服」；工程保留 `outfit` 模块、既有目录与「布米嘴替开评」口播标识，便于与当前部署和调用记录对应。

先做无副作用检查：

```sh
python3 deploy/install_robot.py --check-only
```

在目标机器人上安装依赖并写入默认待机配置：

```sh
python3 deploy/install_robot.py --sdk-root /absolute/path/to/matching-media-sdk
.venv/bin/python configure_robot.py
.venv/bin/python robot_service.py --check
```

配置工具以隐藏输入读取模型凭证，只保存在本机。新机器不随仓库带密钥；厂家媒体扩展、动态库和 DDS 配置也不在仓库中，需要使用设备配套版本。

需要独立用户服务时，继续按[部署说明](docs/DEPLOYMENT.md)操作。上述步骤不会启用收音、拍照或播声。

## 代码入口

- `robot_service.py`：本机常驻口令流程；未启用硬件时只待机。
- `robot_demo.py`：单张已有图片的云端流程验证；默认只保存 WAV。
- `configure_robot.py`：本地私有配置入口。
- `outfit/`：视觉、提示词、声音、口令、相机、媒体适配与调用记录。
- `deploy/`：安装器与用户服务模板。
- `tests/`：使用替身的程序检查，不自动访问硬件或真实云端。

开发检查：

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```
